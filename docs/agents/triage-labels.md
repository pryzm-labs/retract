# Triage labels

Each role uses the GitHub label of the same name.

| Role and GitHub label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The issue is specified well enough for an agent to implement independently. |
| `ready-for-human` | The issue requires human implementation. |
| `wontfix` | The maintainer has decided to close the issue without implementing it. |
